The frontend work has been done in the index.html file
It consist of easy processes like:
1. Product Catalog / Gallery
    Displays all available candles in a structured layout. Each product will include an image, name,
    price, and short description. Users can browse different candle designs easily.
2. Product Search
     Allows users to search for candles by name. The system will dynamically filter products and display
     matching results in real time using JavaScript.
3. Product Category Filtering
    Users can filter candles based on categories such as scented, decorative, or festival candles. This
    helps users find specific types of products quickly.
4. Product Details Page
    When a user selects a product, a detailed view will be shown including a larger image, full
    description, price, and product information.
5. Shopping Cart Management
    Users can add products to the cart, remove products, update quantities, and view the total price.
    Cart data will be stored using browser local storage.
6. Checkout / Order Simulation
    Provides a checkout interface where users enter delivery information and confirm their order. The
    system will display an order summary and confirmation message without real payment processing.
7. Wishlist / Favorite Products
    Allows users to save products they like for future purchase. Saved items will be stored in local
    storage and can be accessed later.
8. Custom Order Request Form
    Users can submit custom candle requests by providing details such as preferred color, scent, or
    message. The form will include input validation.
9. Contact / Feedback Form
    Users can send messages or feedback to the website owner. The system will validate user input
    before submission.
10. Recently Viewed Products
    The system tracks and displays products that the user has recently viewed, allowing quick access
    to previously explored items.
